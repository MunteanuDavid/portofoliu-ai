# Portofoliu AI

Secțiunea de portofoliu pentru site: postere pe Instagram, landing page pe laptop și video TikTok.

## Structură
- `index.html` – secțiunea de portofoliu (se deschide direct în browser)
- `assets/` – pozele și video-ul optimizate pentru site, folosite de `index.html`
- `originale/` – fișierele originale, la calitate maximă (postere, video Higgsfield, poze de produs)

## Cum o vezi
Descarcă proiectul (butonul verde **Code**, apoi **Download ZIP**), dezarhivează-l și deschide `index.html` în browser.
